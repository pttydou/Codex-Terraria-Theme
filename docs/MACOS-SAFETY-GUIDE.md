# macOS 提示“无法验证或不安全”时的操作教程

这个皮肤切换器是本地脚本工具，没有购买 Apple Developer ID，也没有经过 Apple 公证。因此，从聊天工具、浏览器或网盘下载后，macOS 可能提示：

- “Apple 无法验证它是否包含可能危害 Mac 安全或泄露隐私的恶意软件”；
- “无法验证开发者”；
- 只有“完成”和“移到废纸篓”，没有直接的“打开”按钮。

这类提示表示文件未经 Apple 公证，不等于系统已经判定它含有病毒。但放行未经公证的脚本仍有风险，只能对来源和完整性已经确认的这一份文件操作。

## 一、先核对再运行

1. 确认 ZIP 来自你信任的人，不要使用群聊里被二次转发、重新打包或改名的版本。
2. 将 ZIP 与旁边的 `.sha256` 文件放在同一目录。
3. 打开“终端”，进入该目录，例如：

   ```bash
   cd "$HOME/Downloads"
   shasum -a 256 -c TRSkin-macOS-2.6.0.12-private-music.zip.sha256
   ```

4. 只有看到 `OK` 才继续。若校验失败，删除文件并重新获取，不要放行。
5. 完整解压 ZIP，不要直接在压缩包预览窗口里运行安装器。

## 二、系统推荐的单文件放行方式

1. 双击解压目录里的唯一入口 `START-CODEX-TERRARIA.app`，让系统产生一次拦截记录。
2. 警告出现后点“完成”或“取消”，不要点“移到废纸篓”。
3. 打开苹果菜单 →“系统设置”→“隐私与安全性”。
4. 向下滚动到“安全性”，找到刚刚被阻止的安装器，点“仍要打开”。这个按钮通常只会在尝试打开后约一小时内出现。
5. 输入当前 Mac 用户的登录密码，再次确认“打开”。
6. 以后同一份文件通常可以直接双击；升级包是新文件时，可能需要重新确认一次。

Apple 官方说明：[打开来自未知开发者的 Mac App](https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac)

## 三、找不到“仍要打开”怎么办

- 先确认你确实尝试打开过完整解压后的 `START-CODEX-TERRARIA.app`，而不是 ZIP 内的预览文件或单独拖出的 App。
- 回到 Finder，按住 Control 点按安装器，选择“打开”；如果仍被拦截，再回到“隐私与安全性”检查。
- 如果 Mac 由公司、学校或家长控制管理，“仍要打开”可能被管理员禁用。此时联系管理员，不要尝试绕过管理策略。

## 四、哪些提示不能按本教程放行

如果系统明确提示“将损坏你的电脑”“已检测到恶意软件”“文件已损坏或被篡改”，请立即停止，不要点“仍要打开”，也不要运行任何解除隔离命令。重新下载并核对 SHA-256；仍然出现时联系提供者。

## 五、不要这样做

- 不要运行 `sudo spctl --master-disable`，不要全局关闭 Gatekeeper。
- 不要对下载目录、主目录或整块磁盘执行递归 `xattr` 清除。
- 不要关闭系统完整性保护（SIP）、防病毒软件或防火墙。
- 安装器不需要管理员权限；如果出现与本文不一致的索取管理员权限、钥匙串、Apple 账户或远程控制请求，请取消。

本工具只安装本地皮肤引擎和控制入口，不修改官方 Codex `.app`、`app.asar`、代码签名、账号、API Key 或模型服务配置。
