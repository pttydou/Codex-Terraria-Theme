## Security model

The switcher does not modify WindowsApps, `app.asar`, Codex signatures, authentication data, API keys, or provider settings. It opens a Chromium DevTools Protocol endpoint on `127.0.0.1` only while a themed Codex session is active. Use the restore entry when the skin is not needed.
